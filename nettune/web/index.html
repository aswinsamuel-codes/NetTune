    How to connect both

    1. Stay connected to the Wi-Fi network on this laptop.
    2. Plug your phone in with a USB cable and turn on USB tethering in the phone's hotspot settings. A Wi-Fi hotspot will not work for this: one Wi-Fi card can join only one Wi-Fi network at a time.
    3. Press Refresh. Both connections should appear above as online.
    4. Press Start combining.

    Good to know: one single stream (one file over one connection) still travels over one link, so it is not faster than that link. Combining uses your mobile data. If a website signs you out or refuses to load, stop combining for that site.
